## 背景与目标

已有文字可见层、Go隐形水印、多图分发与质量策略。可见层不能使用品牌图片，不能避开正文/二维码等区域；正式Web输出仅PNG，实验室JPEG结果不能直接视为正式导出能力。

本轮建议打通“上传原图与Logo → 为每张图设置可见层和避让 → 确认预览 → 按固定选项输出 → 验证最终文件后交付”。以下三项范围及默认值来自建议，尚待本快照确认；不自动纳入其余候选。

## 用户场景

1. 管理员为单图双水印或多图任务上传Logo，选择文字、Logo或两者组合，设置位置、比例、透明度，查看每份实际预览后生成独立隐形副本。
2. 管理员逐张框选正文/人脸/二维码等不希望被可见水印遮挡的矩形区域，在桌面和手机预览下确认实际避让；切换图片不错误复用其他图片的坐标。
3. 管理员在单图Go模式（含双水印）或多图任务选择PNG/JPEG；JPEG按所选质量编码后实际提取并检查最终质量，不合格则明确失败。
