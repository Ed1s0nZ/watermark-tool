# 表单工作区需求

状态：Confirmed，2026-10-27。来源：用户明确确认上一轮所列三项，并要求先做完；本文件记录该已确认方案，不新增产品政策。

## 需求

- REQ-001：双水印、多图任务按上传素材、配置水印、预览确认、生成下载形成清晰分区；复杂样式、避让、策略管理、输出与质量置于默认收起的高级配置。
- REQ-002：桌面配置与预览并排；配置滚动时预览保持可见，长预览自身可滚动；手机配置/预览可切换，保留输入与生成状态，提供明确返回入口。
- REQ-003：所有用户可选文件入口采用统一交互：选择/拖拽、文件名/格式/大小、图片缩略图、替换与删除；多文件保留各项管理及显式追加入口。
- REQ-004：沿用当前格式、大小、数量和总量限制，错误可见，非法选择不覆盖有效素材；忙时禁止变更；删除/替换必须使依赖的预览和下载失效。客户端预检不替代服务端验证。
- REQ-005：不自动上传、不覆盖原文件、不新增文件持久化；重复选择同文件可触发，移除/替换/离开页面释放缩略图资源。CSV删除仅清除导入文件引用，不清空用户已编辑的名单文字。
- REQ-006：保留中文/英文、明暗主题、键盘操作及现有生成、取消、重试、验证与下载。可见预览与最终验证成品明确区分；更改配置后须重新预览。

## 验收

- AC-001（001）：两种复杂表单上传在前、基础字段可直接访问、高级默认收起，展开/收起不丢值。
- AC-002（002）：1280px并排/粘性定位与390px切换，切换后文件/字段/预览不丢失，生成与错误可见，无横向页面溢出。
- AC-003（003–005）：真实选择与拖拽、格式/大小/数量拒绝、单图替换删除、Logo、CSV和多图追加/逐项替换删除均生效；忙时禁止操作，无自动处理请求。
- AC-004（004,006）：双水印和多图真实生成、提取验证/ZIP下载通过；变更素材或配置清除旧预览/下载，失败可修正重试。
- AC-005（005,006）：所有现有文件入口复用组件，中英文暗色/手机可用，生产构建和完整浏览器回归通过。

保守实现选择：分区可直接编辑而非强制向导锁步，避免返回时重复操作；不扩展到首页/任务列表重构、后台API或新的业务功能。
