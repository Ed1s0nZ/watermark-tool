# C5：混合目录任务运行时

`internal/filetasks` 管理已接收副本、不可变处理计划、队列、逐文件执行/报告和临时归档；HTTP/UI/协作审批桥接在C6继续，此处未标C完成。

## 实际行为

- 目录及ZIP通过同一服务端Ingester入私有随机目录。真实格式预检后固定源ID/路径/摘要/字节、参数、实际PDF页计划、输出重名映射和服务端时间；单文件不支持/损坏为明确计划错误，不把整个有效目录伪装失败。非法ZIP/路径接收失败则整体回滚。
- 后台共用处理槽，接收预检也占槽，关闭会等待真实写入结束。排队/每文件尝试/终态及服务端开始结束时间持久化；取消不启动剩余文件，失败或取消最多三次尝试，成功项始终不重做。参数变更须新建任务。
- ZIP只含已验证成功项，逐项完整JSON报告及准确JSON/CSV清单；CSV防公式解释，成品逻辑路径在files/下，与reports/及manifest隔离。ZIP关闭后重新读取每项/CRC、记录最终SHA；下载重新检查同一文件描述符的SHA及当前授权。
- 任务快照摘要排除运行状态/次数/结果，纳入不可变源、计划、参数、key与时间。运行前/每文件/提交/下载调用当前授权及固定密钥有效性回调；处理中撤权会删除未提交成品，阻止下载。审批规则本身仍由C6接workspace，不能将回调测试称作完整审批集成。
- AES-GCM加密完整任务状态，AAD绑定用途版本/团队；0700目录/0600文件、单写进程锁、临时fsync/原子rename/目录fsync，错误密钥/篡改/写失败拒绝继续。物理路径不入JSON，只从服务端ID重构。
- 每团队32任务/100文件，输入沿用128MiB累计/50MiB单项；请求配置512KiB、正式计划1MiB、加密状态16MiB，并为每项后续结果/尝试保留6KiB空间。只持久compact结果，完整报告入私有临时artifact。归档128MiB、输出及报告预留4MiB打包空间；目录逻辑磁盘2GiB，准备/运行保守预留，非进程内存硬隔离或全平台跨团队磁盘硬配额。
- 输入15分钟；成品默认1小时，可缩短。清理跳过仍有写入所有权的任务，移除过期材料而保留生成事实；异常清理可观察。重启将排队/运行标为中断，移除未提交输出/孤儿临时目录；没有自动重启或捏造成功。显式删除终态任务可释放历史容量。

## 验证

Go1.26 `go test -race ./internal/filetasks ./internal/fileprocess ./internal/filebundle`及所涉vet通过；运行时专项复验7.853s，先前连续两轮race通过21.149s。

测试真实七文件混合目录（六格式成功+不支持类型失败）、完整ZIP数据流/CRC/报告/原空目录；三次仅失败项重试，成功输出mtime和尝试数不变；快照结果前后相同；加密文件无正文/账号/文件名明文；变更源摘要拒绝；审批回调前置拒绝与实际执行后撤权；已生成ZIP篡改拒绝；真实运行取消等待写入结束且保留输入、无取消成品；进程锁/错误key/跨团队AAD/密文篡改/注入持久写失败拒绝；真实排队重开为中断、恢复执行、模拟时钟输入及成品到期、删除；大配置/双槽占满/2GiB稀疏文件模拟逻辑配额均拒绝且无新输入残留。

维护性：接收/队列、状态加密、执行、打包、清理、快照/预检分模块，生产文件均小于400行；调度只扫描队列ID，不每100ms克隆完整历史。临时日志 `/tmp/workspace-c5-{verified-race,final-runtime,final-runtime-vet,race-repeat}.log`。
