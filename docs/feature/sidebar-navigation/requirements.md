# 二级侧边栏需求

状态：已确认。沿用已向用户展示的分组方案及后续“最佳实践优化”执行指令。

## 产品与交互契约

- 工作台为独立入口。
- 水印制作：添加水印、双水印模板。
- 分发管理：多图分发任务、批量副本、分发记录。
- 验证分析：提取水印、批量溯源、效果实验室。
- 系统管理：密钥版本、操作审计、设置。
- 最多两级，现有十二个页面和 URL hash 保持兼容。
- 页面跳转、刷新和浏览器历史变化自动展开所属组并选中页面。允许用户手动展开多个组或关闭当前组。
- 桌面折叠时使用 Ant Design 原生浮层；手机抽屉始终显示完整二级导航，不受桌面折叠状态影响。选择页面后关闭抽屉。
- 底部状态和折叠按钮固定，导航内容独立滚动。保留中英文、明暗主题和键盘操作。

## 验收

1. 十二个页面入口各出现一次，分组与上述契约一致。
2. 直接链接、刷新、前进后退、工作台快捷入口均正确同步选中和展开状态。
3. 桌面收起浮层可跳转，展开后正确恢复当前分组；手机导航独立可用。
4. 中英文与暗色模式无横向溢出；短屏侧边栏仍到底，底部按钮可见。
5. 构建与原有平台端到端流程全部通过，无后端接口或数据变更。
