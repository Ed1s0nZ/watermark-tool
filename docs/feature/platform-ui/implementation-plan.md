# 实施计划

- 分支：main；需求：requirements.md；设计：design.md。
- 范围：已确认的平台界面与单管理员鉴权；不增加用户库或任务历史。

| 切片 | 模块/行为 | 验证 | 文档/回滚 |
| --- | --- | --- | --- |
| 服务端 | internal/auth、cmd/server；会话接口、同源保护、API 鉴权、并发限流、静态入口与请求体限制 | Go HTTP 测试、race、真实 PNG 往返 | README API 迁移；按功能提交回滚 |
| 前端 | web/frontend；React/Ant Design 布局、登录、工作台、文件操作、设置、词典与偏好 | tsc、Vite build、浏览器关键路径 | README 构建；前后端共同回滚 |
| 收尾 | 移除旧静态界面，更新 CHANGELOG 与验证记录 | git diff --check、Go 全套测试、构建与移动端检查 | main 推送与干净状态 |

依赖顺序：契约 → 服务端与前端实现 → 集成验证 → 使用文档与变更记录 → 提交推送。

构建产物不入库，忽略 node_modules、dist、测试输出和本地环境文件。测试用账号仅由测试代码/运行进程提供，不保留真实凭据。浏览器检查使用本地服务；不创建 PR、不部署外部环境。

未决问题：无阻塞项。现有算法局限和超时实现不在此次重写范围。
