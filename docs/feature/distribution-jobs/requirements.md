## 背景与目标

已有单图多人独立副本、持久登记和密钥版本；已有单图双水印、效果实验室与报告。当前多张素材仍需逐张操作，可见姓名不能随名单批量生成，HTTP路径日志不能回答具体业务操作结果。

建议本轮打通“多张原图＋接收人名单 → 后台生成每人整套副本 → 下载及追溯 → 查询操作记录”。本快照将上轮推荐具体化，不视为全部候选均获批准，也不继承上一轮确认。

## 用户场景

1. 管理员上传多张原图、导入名单，确认文件/人数与模式，创建任务；页面显示真实进度，刷新后仍能查询。
2. 选择批量双水印，设置文字“内部资料 · {name} · {recipient_id}”；每个接收人得到带自己文字和独立隐形标识的整套图片。
3. 任务中断/失败后查看原因，按要求补齐相同原图后重试；运行中可取消，不能收到冒充完整包的部分结果。
4. 管理员查阅创建/重试/取消/下载、密钥变更及验证等操作记录，明确其只是登录账号的服务端观察结果。

## 失败与恢复约定

- 局部完成不等于任务已成功，ZIP就绪和完整登记提交完成后才可下载；下载响应完成也不等于收件人实际收到。
- 浏览器关页不等于取消后台任务；必须有显式取消入口。刷新/会话过期后重新登录可查状态，不自动重复提交。
- 任务输入/密钥/临时文件不足或渲染不一致时明确恢复步骤，不换输入或密钥“悄悄修复”。
- 审计保护依赖受限服务器和备份，不对持有主密钥的管理员承诺不可伪造；不新增对外可信签章。
- 本轮不研究新的抗裁剪、缩放或拍屏算法，不扩展PDF/视频处理。
