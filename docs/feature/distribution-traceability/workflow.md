## Feature Lifecycle Report

- 功能：批量副本与可核验的登记溯源。
- 当前行为：一图一文本、单环境密钥，无数据库或分发历史。
- 期望行为：一图多人副本、记录检索、验证后关联登记信息、密钥版本轮换及旧文件恢复。
- 影响边界：独立持久存储/密钥管理域、现有盲水印服务适配、HTTP/CLI（迁移运维）、Web 新页面与查询结果。
- 公共接口影响：预计新增批次、记录、密钥元数据能力；保持现有默认调用与 v1 夹具兼容。接口细节待确认后设计，未在 UI 中先行发明。
- 授权/安全：只操作本地副本和持久记录；无消息/邮件发送授权；不得在网页/日志返回密钥材料。
- 文档载体：本目录 requirements.md；后续 design.md / implementation-plan.md / verification.md。
- 测试需求：真实多人副本映射、并发幂等、持久化失败/重启/损坏、旧密钥迁移、授权与秘密不泄露、浏览器流程、既有回归。
- 文档/变更记录：实现时更新 README 与根目录日期分类 CHANGELOG；当前仅为需求草案，不宣称新增能力已完成。
- 提交计划：本阶段文档提交推送 main；需求明确确认后分阶段设计、实现、验证与交付。
- 阻塞/假设：需求快照待确认；尤其是元数据与原始文件留存边界。
